🎬 Netfloat – A Movie Discovery & Review Web App

Netfloat is a clean, fast, visually cinematic movie browsing UI built using React + Tailwind + OMDB API.
Think of it as a minimal Prime-Video-style catalog app where users can browse by category, view featured films, search, and rate movies.

🚀 Features
🖼️ Big Cinematic Hero Slider

Smooth transitions

Movie info & “View details” button

🎞️ Movie Categories

Action & Adventure

Sci-Fi & Fantasy

Drama

Comedy

More coming…

⭐ User Rating System

Users can rate movies themselves using stars — saved client-side.

🧠 Tech Used

React

Vite

Tailwind CSS

OMDB API

Context API

Custom hooks

🛠️ Getting Started
1️⃣ Install Dependencies

Run this in the project folder:

npm install

2️⃣ Start Dev Server
npm run dev

3️⃣ Open Browser

Visit:

http://localhost:5173

🔑 OMDB API Key

https://www.omdbapi.com/apikey.aspx

Then update:

omdb.js
